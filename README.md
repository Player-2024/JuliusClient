# Julius Client

Julius Client is a custom Minecraft launcher and client for Linux, primarily developed for Ubuntu.

It combines Minecraft launching, instance management, mod browsing, modpack management and Minecraft server administration in one application.

> Julius Client is currently in active development.

## Features

- Custom Minecraft launcher
- Minecraft instance management
- Vanilla and Fabric support
- Modrinth integration
- CurseForge integration
- Visual mod browser with project icons
- Instant search while typing
- Modrinth `.mrpack` import
- CurseForge profile import
- Visual modpack library
- View installed Mods, Resource Packs and Shaders
- Java runtime detection
- Configurable memory settings
- 4K / HiDPI support
- High refresh-rate optimized interface
- F11 fullscreen mode
- Integrated Minecraft server control
- Live server console
- Start / Stop / Restart controls
- Plugin management
- Server monitoring

## Modrinth

Julius Client can use Modrinth for:

- Mod search
- Resource Pack search
- Shader search
- Project metadata
- Project icons
- File downloads

## CurseForge

CurseForge integration is designed for:

- Mod search
- Resource Pack search
- Project information
- Project artwork
- File downloads
- CurseForge modpack importing

A valid CurseForge API key is required for CurseForge API requests.

API requests are only made when CurseForge content is being browsed or installed. Local caching is used where possible to reduce unnecessary API traffic.

## Platform

Primary development platform:

- Ubuntu Linux
- Python
- PySide6 / Qt 6

Other Linux distributions may also work but are not currently the main development target.

## Project Status

Julius Client is still under active development.

Some features, interfaces and supported Minecraft versions/loaders may change between releases.

Current development focuses on:

- Launcher stability
- Performance
- Mod browsing
- Modpack management
- CurseForge integration
- Minecraft server administration

## Privacy & Security

Julius Client stores its configuration locally.

API keys, account credentials, private keys, tokens and other secrets must never be committed to this repository.
